# Ноктюрн — тихий планер

Личный планер-календарь, PWA. Работает офлайн, данные хранятся только на устройстве (IndexedDB).

## Запуск на компьютере

```bash
npm install        # один раз
npm run dev        # режим разработки: http://localhost:5173
npm test           # тесты логики дат, повторов и быстрого ввода
npm run build      # сборка в папку dist/
npm run preview    # посмотреть собранную версию: http://localhost:4173
```

Service worker (офлайн) включается только в собранной версии (`build` + `preview` или на хостинге).
Иконки пересобираются командой `npm run icons`.

## Опубликовано

**https://xqwxqxqwx.github.io/nocturne/** — GitHub Pages, ветка `gh-pages`.

Обновить сайт после изменений в коде: `npm run deploy` — прогонит тесты, соберёт проект
и опубликует `dist` в ветку `gh-pages`. Сайт обновится примерно через минуту.
Код храни в ветке `main` как обычно (`git commit` + `git push`).

## Как открыть на телефоне

PWA (установка, офлайн, уведомления) требует **HTTPS** — его даёт GitHub Pages.
Пути в сборке относительные (`base: './'`), поэтому приложение работает в подпапке `/nocturne/`.

### Установка на главный экран
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

## Напоминания
Используется Notification API. Бэкенда нет, поэтому напоминания приходят, пока приложение открыто
или свёрнуто (браузер может «усыпить» его в фоне). На iOS — только у установленного PWA, iOS 16.4+.
Если уведомления не поддерживаются, приложение работает как обычно.

## Данные
Настройки → «экспорт в JSON» сохраняет всё в файл; «импорт» полностью заменяет данные файлом.
Делай экспорт время от времени — если очистить данные браузера, дела пропадут.

## Структура
```
src/
  domain/      типы, даты (неделя с пн), повторы, быстрый ввод — без зависимостей от UI
  db/          Dexie: items, settings + таблицы этапа 2 (habits, habitLogs, dayNotes)
  notify/      планировщик напоминаний
  components/  навигация, свайп-строка, таймлайн, редактор, быстрый ввод, SVG-графика
  screens/     День/Сегодня, Неделя, Месяц, Настройки
sw/sw.js       шаблон service worker (список файлов подставляется при сборке, см. vite.config.ts)
public/        манифест и иконки
```

## Этап 2 (заложено)
- В базе уже есть таблицы `habits`, `habitLogs`, `dayNotes`; они попадают в экспорт/импорт.
- Статистика считается из `doneAt` (разовые) и `doneDates` (повторы) у дел.
- Новый экран = файл в `screens/` + вкладка в `components/Nav.tsx`.
